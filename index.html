Deploy to DigitalOcean App Platform

Free-tier eligible Static Site deployment via GitHub

  1. Push this single index.html file to a GitHub repository: 
    mkdir usc-prelaw-suggestor && cd usc-prelaw-suggestor
# Save this file as index.html in this folder
git init
git add index.html
git commit -m "Initial commit: USC Pre-Law & AI Pathway Suggestor"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/usc-prelaw-suggestor.git
git push -u origin main
  2. Create a Static Site in DigitalOcean:

    Log into the DigitalOcean Cloud Console → click App Platform → Create App → connect your GitHub repository (usc-prelaw-suggestor) on branch main.

  3. Configure as a Static Site (Starter / Free Tier):

    DigitalOcean auto-detects index.html as a Static Site. Leave the Build Command blank, set Output Directory to /, and click Create Resources.

  4. Optional: One-click .do/app.yaml spec: 
    name: usc-prelaw-ai-suggestor
static_sites:
  - name: web
    github:
      repo: YOUR_USERNAME/usc-prelaw-suggestor
      branch: main
      deploy_on_push: true
    index_document: index.html
